# Mi Cuaderno

Mi app personal: agenda, libros, deporte, idiomas y notas.

## Cómo instalarla en el iPhone
1. Abre la dirección de la app en **Safari**.
2. Toca el botón **Compartir** (el cuadrado con la flecha).
3. Elige **Añadir a pantalla de inicio**.

## Dónde se guardan mis datos
Solo en el iPhone donde la uses. En **Más → Copia de seguridad** puedes guardar una copia en Archivos o iCloud Drive, y recuperarla si cambias de móvil.

## Cómo se publica
Cada cambio en la rama `main` se publica solo con GitHub Pages (`.github/workflows/publicar.yml`). Los iconos se generan con `tools/make_icons.py`.
